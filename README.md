# Teachers' Books and Experiences Portal

A public portal where teachers publish books and share teaching experiences, built alongside the research competition platform for the Ministry of Education in Kermanshah, Iran.

Visitors browse and search published work and see the most-viewed books and experiences. Teachers register, manage their profile and submit or update their own work.

## Features

- **Landing page** with platform statistics, top books and top experiences, and featured videos
- **Browse and search** books and teaching experiences, with detail pages
- **Accounts:** registration (including a teacher route), login and profile editing
- **Submissions:** teachers add and update their own books and projects
- **Leaderboards** of the most-visited content

## Tech stack

- [Nuxt 3](https://nuxt.com) (Vue 3)
- Tailwind CSS
- REST API backend (shared with the research competition platform)
- Docker for deployment

## Running locally

```bash
npm install
npm run dev      # http://localhost:3000
npm run build
```
